# Drop scene files here

Put your raw scene clips/images in this folder (subfolders are fine, e.g. `public/scenes/01-gym.mp4`).

Anything here is a static asset Remotion can reference with `staticFile("scenes/01-gym.mp4")`. Once files land here, ask Claude to build the composition and it will sequence them into a video.

This file is just a placeholder so the folder exists in git — it's not used by the video.
